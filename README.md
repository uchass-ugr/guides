# Guías de trabajo de U\^CHASS

Guías breves para los miembros de [U\^CHASS](https://uchass.ugr.es) (Universidad de Granada) sobre cómo trabajamos.

Son **recomendaciones, no obligaciones**. Cada proyecto y cada investigador principal (IP) pueden adaptarlas. Si algo no encaja con tu caso, haz lo que tenga sentido y, si crees que la guía debería cambiar, abre un *issue*.

## Guías

| Guía | De qué trata |
|------------------------------------|------------------------------------|
| [Cómo organizar un proyecto](repositorios/projects.md) | Cómo organizar el repositorio de un proyecto o de un paper: estructura, datos abiertos y restringidos, licencias y cita |
